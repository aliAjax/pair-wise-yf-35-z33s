常用接口

GET  /health
GET  /api/<kind>                       # 运动员/样本/案件：athletes, samples, cases；豁免：tues
GET  /api/results                     # 结果视图：受保护标记 + 关联案件（可用 ?athlete_id= 过滤）
POST /api/tues                        # 医生登记豁免：athlete_id, substances, valid_from, valid_to
GET  /api/entities/<id>
POST /api/entities/<id>/actions       # tue: approve/reject/revoke；sample: analyze/report_adverse
